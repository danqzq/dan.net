# Room

The `Room` class represents a room in the Dan.Net server. It contains information about the room, such as the room name, the list of players in the room, and the room's state.

## Properties

### `name` (string)

The name of the room.

### `maxPlayers` (byte)

The maximum number of players that can join the room.

### `currentPlayers` (byte)

The current number of players in the room.

### `creatorId` (string)

The ID of the player who created the room.
